# Downloads Folder

Place downloadable files here. They will be served at `/downloads/filename.ext`.

## How to add a new document:

1. Place the file in this folder (e.g., `Solar_Hail_Claims_Guide.pdf`)
2. Update `public/data/meta/downloads-catalog.json` to add an entry for it
3. Or use the Admin "Add Document" button in the dashboard (saves to localStorage)

## Naming convention:
- Use underscores instead of spaces
- Include descriptive name: `Thermal_Boiler_Failure_Guide.pdf`
- Keep file names under 50 characters
